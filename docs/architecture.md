# معماری — Architecture

## نمای کلی

واژه‌سفر یک بازی تک‌صفحه‌ای (SPA) کاملاً سمت کلاینت است. Next.js فقط نقش هاست/شل را دارد؛ **موتور بازی کاملاً مستقل در `src/game/`** نوشته شده و هیچ وابستگی به React ندارد. این جداسازی باعث می‌شود:

1. بازی بتواند به هر هاست استاتیک منتقل شود.
2. در آینده با Capacitor به اپ بومی موبایل تبدیل شود.
3. منطق بازی قابل تست بدون DOM/React باشد (مثل `scripts/validate_words.ts`).

```
page.tsx (React shell)
   └── game.mount(div#vz-host)      ← یکتا با گارد StrictMode
        └── Game (engine.ts)
             ├── Scene Manager      ← go({kind}) + cleanup تابعی
             ├── screens.ts         ← منو/فصل/مراحل/تنظیمات/پیشرفت/جوایز
             └── gameplay.ts        ← صحنه زنده + جدول + چرخ + جشن‌ها
```

## جریان اصلی گیم‌پلی

```

                                                      │

```

## تصمیم‌های کلیدی

### ۱. کراس‌ورد راست‌به‌چپ (`crossword.ts`)
- حرف اول واژه افقی در **راست‌ترین ستون** قرار می‌گیرد و واژه به چپ رشد می‌کند (`c - i`).
- استخراج «ران»ها: افقی‌ها قبل از مقایسه **reverse** می‌شوند (چون از چپ خوانده می‌شوند)، عمودی‌ها نه.
- اعتبارسنجی کامل: هر ران ≥۲ باید دقیقاً یکی از واژه‌های مرحله باشد → هیچ واژه تقلبی روی صفحه ظاهر نمی‌شود.
- **بهترین از ۴۸ نمونه**: هر چیدمانِ معتبر امتیاز می‌گیرد (مساحت + جریمه جزیره) و فشرده‌ترین انتخاب می‌شود؛ چیدمان‌های پراکنده حذف می‌شوند.
- Deterministic است: `seed = levelId*100 + chapterId` → همان چیدمان برای همه بازیکنان.

### ۲. چرخ حروف (`ui/wheel.ts`)
- Pointer Events با `setPointerCapture` → روی موبایل و دسکتاپ یکسان کار می‌کند.
- Backtrack: عبور دوباره روی حرف قبلیِ مسیر، آن را حذف می‌کند.
- شعاع چرخ = `min(width, height)/2 - 34` تا در صفحه‌های کوتاه هم حروف از کادر بیرون نزنند.
- `ResizeObserver` موقعیت حروف را همیشه با ابعاد نهایی همگام می‌کند.

### ۳. صدا (`core/audio.ts`)
- **موسیقی**: یک سکونسِر ۱۶گام با نگاه‌افکنی ۰.۳۵ ثانیه. ملودی از موتیف ۴نتیِ در حال جهش روی گام فصل.
- گام‌ها بر حسب **cents** تعریف شده‌اند تا کوک‌های ربع‌پرده (کرن) ممکن شود — الهام از دستگاه‌های ایرانی، بدون کپی ملودی خاصی (الگوریتمی و تولیدی).
- سازها: Pluck سه‌گوش با غنی‌سازی اکتاو (سانتورمان)، درون سینوسی با LFO تنفس، ضرب دف‌مانند (نویز باندپس + تامپ سینوسی).
- **SFX**: تماماً سینتز زنده — بدون فایل. (SFX_BUS و MUSIC_BUS جدا با کمپرسور روی مستر)

### ۴. دنیای زنده (`fx/props.ts` + `fx/particles.ts`)
- ۴۳ پراپ SVG پارامتریک (دو رنگ از پالت فصل می‌گیرند) — واژه nاُم → پراپ nاُم از استخر فصل، در zoneهای از پیش چیده با جیتر seed-دار.
- موتور ذرات تک-کانواس: emitterهای محیطی هر فصل (گلبرگ/غبار/شن/شب‌تاب/برف/پرد دریا/برگ/ستاره/مه/طلای برفی) + burst واژه، کانفتی و آتش‌بازی چندگلوله.
- روی دستگاه‌های ضعیف `intensity` (تعداد ذرات) خودکار کم می‌شود.

### ۵. ذخیره‌سازی (`core/save.ts`)
- ساختار نسخه‌دار `{v:1, ...}` با merge تدافعی → آپگریدپذیر.
- کلید قفل‌گشایی: فصل n+1 با کامل‌کردن **۷ مرحله از ۱۰** فصل n باز می‌شود (`CHAPTER_UNLOCK_THRESHOLD`).
- همه‌چیز در `localStorage` با کلید `vazhe_safar_save_v1`.
