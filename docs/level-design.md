# راهنمای مراحل و سختی — Level Design Guide

## ساختار داده

هر مرحله در `src/game/data/levels/chNN.json` (NN = شماره فصل ۰۱ تا ۱۰):

```json
{
  "id": 11,                    // شناسه جهانی ۱..۱۰۰
  "wheel": "بازار",             // حروف چرخگردان (طولانی‌ترین واژه)
  "words": ["بازار", "راز"],    // واژه‌های اصلی جدول (کراس‌ورد)
  "bonus": ["با", "را"]         // واژه‌های پنهان مخصوص همین مرحله
}
```

## قوانین اعتبارسنجی (خودکار توسط `scripts/validate_words.ts`)

1. هر واژه (اصلی و پنهان) باید فقط با حروف چرخ قابل ساخت باشد (چندمجموعه).
2. طولانی‌ترین واژه اصلی باید از همه حروف چرخ استفاده کند (استثنا: مراحل آموزشی).
3. بدون واژه تکراری؛ حداقل ۲ واژه اصلی.
4. مولد کراس‌ورد باید بتواند چیدمانِ فشرده بسازد (مساحت ≤ ۲.۳۵ برابر خانه‌های پر).

## افزودن مرحله جدید

1. در فایل JSON فصل موردنظر، یک ردیف جدید با `id` پیوسته اضافه کنید.
2. `bun scripts/validate_words.ts` را اجرا کنید — باید ۰ خطا بگیرید.
3. پراپ‌های صحنه به‌صورت خودکار از `propPool` فصل (`data/chapters.ts`) انتخاب می‌شوند؛ نیازی به تنظیم دستی نیست.

## افزودن فصل جدید

در `data/chapters.ts` یک `ChapterTheme` جدید اضافه کنید: عنوان، پس‌زمینه (`public/assets/bg/`)، پالت دو رنگ پراپ‌ها، اکسنت UI، نوع ذرات محیطی، پیکربندی موسیقی (گام cents/تمپو/ضرب)، استخر پراپ‌ها، zoneهای جای‌گذاری و پایان‌بندی (`finale`). سپس `chNN.json` مراحل آن را بسازید.
