# واژه‌سفر — Safar-e Vazhe 🌙

**سفری واژه‌به‌واژه در سرزمینِ قصه‌ها**

یک بازی پازل کلمات موبایلی، **اورجینال** و ایرانی‌الهام: با پیدا کردن هر واژه، دنیای بازی جان می‌گیرد — درخت‌ها سبز می‌شوند، چراغ‌های بازار روشن می‌شوند، کاروان از کویر می‌گذرد و ستاره‌ها در آسمان ظاهر می‌شوند.

> an original, Iranian-inspired word-puzzle journey where every discovered word brings a living world to life.

### 🆕 تغییرات نسخهٔ ۱.۱۵.۰ — مهندسی کامل سرعت: خداحافظی با لگ و داغ‌شدن + فروشگاه اختصاصی + آمادهٔ مایکت و بازار
- ⚡ **دیباگ ریشه‌ای لگ (۳ عامل اصلی پیدا و حذف شد):**
  1. **ConvolverNode دائمی حذف شد** — یک کانولوشن استریوی ۲.۷ ثانیه‌ای روی **هر** تیک صوتی، همیشه اجرا می‌شد؛ روی گوشی‌های ضعیف CPU دائمی می‌سوزاند، **گوشی داغ می‌کند** و رندر گرسنه می‌ماند. گراف صدا حالا فقط Bus→Master→Compressor است (نزدیک صفر CPU).
  2. **رندر مجدد کل اپ با هر سکه حذف شد** — قبلاً هر رویداد سکه (هر واژه، هر راهنما) کل درخت اپ از جمله چرخ و وردبورد را re-render می‌کرد = همان «لگ موقع حدس کلمه». حالا هر نما فقط با هوک‌های باریک (`useCoins`) خودش subscribe می‌شود؛ تغییر سکه فقط یک سکه‌پیل کوچک را آپدیت می‌کند.
  3. **نوشتن همگام localStorage حذف شد** — قبلاً با هر رویداد JSON کامل سیو روی ترد اصلی دیسک می‌نوشت. حالا debounce شده (حداکثر یک نوشتن در ۹۰۰ms) + flush تضمینی هنگام خروج/پس‌زمینه.
- 🐉 **پاسچ FPS + حالت lowfx خودکار**: اگر دستگاه ضعیف باشد، خودکار همهٔ انیمیشن‌های تزئینی خاموش و شمارش ذرات جشن کم می‌شود — بازی در هر گوشی روان می‌ماند.
- 🛒 **فروشگاه کاملاً نو و اختصاصی**: هویت شب‌طلایی پریمیوم، تب‌های «سکه‌ها / ویژه / سکهٔ رایگان»، مدال سکه، روبان «پرفروش‌ترین»، بج هدیه (+۱۵٪ تا +۴۰٪)، بستهٔ طلایی مسافر و «حذف تبلیغات» — بدون backdrop-blur، انیمیشن‌ها فقط transform/opacity.
- 💰 **آمادهٔ پرداخت درون‌برنامه‌ای مایکت و کافه‌بازار**: لایهٔ `monetization.ts` با پل JSON ثابت (`VzBilling` / `VzAds`)؛ اتصال واقعی فقط یک پلاگین کوچک Capacitor می‌خواهد (راهنما در همین فایل). تا آن موقع، کل جریان خرید **شبیه‌سازی‌شده** قابل تست است.
- 📺 **آمادهٔ تبلیغات**: جایگاه ویدیوی جایزه‌محور (Rewarded) «سکهٔ رایگان» با کول‌داون ۳ دقیقه‌ای — در وب با یک پلن‌شبیه‌ساز دمو، در اندروید به AdMob وصل می‌شود. محصول «حذف تبلیغات» در سیو ذخیره می‌شود.
- 🎵 **موسیقی صفحهٔ اصلی از نو ساخته شد** (قبلی «رو مخ» بود): تم جدید «دلنواز و ریتمیک» در دستگاه شورِ رِ با ریتم ۶/۸ — سنتور + نی + تنبک/دف + بیس نرم؛ لوپ بی‌درز ۲۶ ثانیه‌ای (`menu2.ogg`، رندر: `scripts/render_menu_v2.py`).
- 🖱️ **بهینه‌سازی درگ**: خواندن layout در هر حرکت انگشت حذف شد (کش rect)، چرخ و وردبورد memo شدند و سکهٔ HUD زیرمجموعهٔ زندهٔ خودش را دارد.
- 🤖 **APK سبک‌تر و سریع‌تر**: R8 + shrinkResources فعال شد (minify) — dex کوچک‌تر، استارت سرد سریع‌تر.
- 🧹 **دیباگ قوی**: lint و tsc بدون خطا، رفع خطاهای SVG (تقارن تاک‌های گوشه)، تست کامل مرورگری از بوت تا برد مرحله.

### 🆕 تغییرات نسخهٔ ۱.۱۴.۰ — ۱۰ فصل سختِ جدید (۲۰۰ مرحله) + موسیقی هر بخش + راه‌اندازی فوری
- 🏔️ **۱۰ فصل سخت جدید (فصل ۱۱ تا ۲۰)** — ۱۰۰ مرحلهٔ کاملاً جدید با چرخ‌های ۷~۸ حرفی و ۶~۱۰ واژه در هر مرحله؛ **صفر واژهٔ تکراری در کل ۲۰۰ مرحله** (اعتبارسنجی خودکار). دنیاهای جدید: جنگل ابرها، دریاچهٔ ماه، غار بلور، تپه‌های سرخ، باغ آسمانی، دریای مرجان، شهر طلا، کوه شفق، قصر یخی و تاج واژه‌ها — هر کدام با **نقشهٔ سفر و پس‌زمینهٔ بازی اختصاصی**.
- 🎵 **موسیقی هر بخش** (خواستهٔ کاربر): صفحهٔ اصلی و منوها تم خودش (`menu.ogg`)، داخل بازی موسیقی اختصاصی هر فصل (`ch01..ch20.ogg` — حالا هر فصل واقعاً موسیقی خودش را دارد) و **بازی دورهمی** تم شاد خودش (`party.ogg`). همه آهنگ‌سازی اورجینال با سازهای ایرانی.
- ⚡ **راه‌اندازی فوری — پایان صفحهٔ آبی**: پوستهٔ اسپلش سِرور-رندر (قبل از بوتِ جاوااسکریپت نقاشی می‌شود)، پیش‌بارگذاری دو مرحله‌ای (حیاتی در اسپلش + بقیه در پس‌زمینه)، رژیم‌های نقشه به‌صورت هوشمند Lazy، و رژیمِ ۹۰٪ سبک‌تر شدن آیکون‌ها (۱.۸MB ← ۱۹۵KB).
- 👤 **پروفایل یکپارچه**: ورود اول فقط اسم می‌پرسد (آواتار اختیاری — هر وقت خواست از کادر پروفایل بالا)، کادر پروفایل مرتب و جمع‌وجور شد و **آواتار داخل کادر پروفایل** است.
- 🏠 **خانه**: کارت «مرحله بعدی» زیر کلاهِ لوگو رفت (دیگر تداخل ندارد) و عدد دیگر متن را نمی‌پوشاند.
- 🎉 **بازی دورهمی ارتقا یافت**: جملات شخصیت‌دار با اسم بازیکن‌ها (ده‌ها جمله برای هر رویداد)، پشتیبانی از اسم انگلیسی، **عمو دانا بازی را یاد می‌دهد و همراهی می‌کند**، ریسمان نور، تشویق شخصی، شعلهٔ زنجیره و سکوی قهرمانی با نورافکن.
- 💡 **آیکون لامپ بزرگ‌تر و زیباتر** شد؛ 🔊 **صدای ستاره/پایان مرحله از نو ساخته شد** (دیگر تیز نیست) و همهٔ صداهای ریز حرفه‌ای‌تر شدند.

### 🆕 تغییرات نسخهٔ ۱.۱۲.۰ — پیاده‌سازی دقیق طرح‌های طراحی‌شدهٔ بازیکن + حذف ریشه‌ای لگ
- 🖼️ **بازسازی دقیق سه صفحه بر اساس عکس‌های طراحی خود بازیکن** («دقیقاً همین عکس‌ها»):
  - **خانه**: صحنهٔ نقاشی‌شدهٔ عمو دانا پای میز چای با گربه‌اش، لوگوی چوبی «واژه‌سفر» با متن طلایی، منوی کنار (فروشگاه/ماموریت‌ها/جوایز روزانه با آیکون‌های سه‌بعدی و برچسب چوبی)، کارت «مرحله بعدی»، دکمهٔ سبز شروع و نوار ناوبری کرم ۵تایی با آیکون‌های کارتونی.
  - **بازی**: HUD کامل (آواتار+نام+نوار XP+سکه+چرخ‌دندهٔ آبی)، بنر چوبی «مرحله X»، واژه‌نامهٔ کرمِ پارچمنی، چرخ حروف چوبی حکاکی‌شده با دایره‌های کرم و ستارهٔ طلایی، گربهٔ کنار چرخ، بُرزنِ سبز و چراغِ راهنمای طلایی با قیمت ۸۰.
  - **نقشهٔ سفر**: هر فصل یک **صحنهٔ نقاشی‌شدهٔ اختصاصی با مسیر سنگی پیچ‌درپیچ** (باغ ساحلی، بازار، کویر، جنگل مه‌آلود، قلعه، شهر بادگیرها، ساحل، روستای پلکانی، شب پرستاره، باغ جشن) + گره‌های سه‌بعدی سرمه‌ای با ستاره روی خود مسیر + **مرز حصیریِ بین فصل‌ها** + تابلوی چوبی + حبابِ گفتگوی عمو دانا + دکمهٔ طلایی «جوایز».
- ⚡ **حذف ریشه‌ای لگ** (کاربر: «بازم لگ داشت»): صفر انیمیشن بی‌پایان روی صفحه‌های اصلی (قبلاً ده‌ها انیمیشن SVG/CSS همه‌جا در حال اجرا بود) — فقط ورودهای یک‌باره + بازخورد لمسی؛ انتقال صفحه‌ها فقط opacity؛ نقشه با تصویر + DOM حداقلی؛ اسپلش سریع‌تر (پیش‌بارگذاری ۱۶ فایل به‌جای ۲۲).
- 🐞 **رفع باگ جدیِ کشیدن حروف**: انیمیشن ورود حرف‌ها، `translate(-50%,-50%)` را دور می‌ریخت و هر حرف نیم‌خانه از ناحیهٔ لمس جابه‌جا بود — کشیدن حس خرابی داشت. هم در CSS و هم در انیمیشن FLIP بُر زدن اصلاح و با درگ واقعی موس تست شد.
- 🎨 **۱۴ آیکون سه‌بعدی رندرشدهٔ جدید** (فروشگاه، کتاب ماموریت، صندوقچه، خانه، کتاب‌ها، چک‌لیست، سکه، هدیه، لامپ، جابه‌جایی، ستاره، چرخ‌دنده، آواتار عمو دانا، بنر لوگو) + ۱۱ صحنهٔ نقاشی‌شدهٔ جدید — همهٔ سبک Royal-Match با کی‌کرامای دقیق (سبز داخل آیکون‌ها سالم می‌ماند).
- 🧹 حجم APK حدود ۱.۲MB سبک‌تر (حذف ۱۱ پس‌زمینهٔ بی‌استفاده).

### 🆕 تغییرات نسخهٔ ۱.۵.۰ — بازطراحی کامل بر اساس طرح مرجع
- 🏙️ **تم جدید: شهر ایرانی + آسمان آبی شاد** — صفحهٔ اصلی کاملاً از نو: میدان مسجد فیروزه‌ای، آسمان ابری شاد، خورشید خندان و «عمو دانا» پای میز چای با گربه‌اش.
- 👴 **عمو دانا — شخصیت راهنمای سه‌بعدی** با ۳ حالت رندر سینمایی (پذیرایی/دست‌در‌هوا/استراحت) و حباب‌های گفتگو در نقشه.
- 🗺️ **نقشهٔ مسیر پیچ‌درپیچ** — جادهٔ طلایی سنگ‌فرش با گره‌های مرحله (کرم=انجام‌شده با ستاره، سبز تپنده=مرحلهٔ فعلی، خاکستری=قفل).
- 🎡 **چرخ حروف چوبی سه‌بعدی** با کشیدنِ خط طلایی بین حروف، ارسال خودکار واژه وسط کشیدن، بُر زدن و راهنمای سکه‌ای.
- 🧱 **جدول واژه‌های ضد-سرریز**: اندازهٔ خانه‌ها با ResizeObserver اندازه‌گیری می‌شود — در بزرگ‌ترین مرحله (۸ واژه) هم صفر پیکسل بیرون‌زدگی (تست‌شده).
- 🎉 **مدال پیروزی بدون لگ**: «عالیه!» سه‌بعدی طلایی، ستاره‌های پاپ‌شونده، کانفتی CSS خالص (بدون canvas و بدون blur) — شخصیت همیشه داخل کادر.
- 📚 **کتابخانهٔ چوبی** (هر فصل یک کتاب)، **ماموریت‌های مادام‌العمر** با نوار پیشرفت، **فروشگاه** با بسته‌های سکه، **چالش روزانه با تقویم شمسی** (Intl فارسی)، **تنظیمات** کامل، **جایزهٔ روزانه** و **صفحهٔ بازگشت** خوش‌آمد.
- 🔘 **دکمه‌های سه‌بعدی اعتیادآور** (سبز/طلایی/آبی/فیروزه‌ای/سرخ) با سایهٔ لبه‌دار و فشردگی واقعی.

### 🆕 تغییرات نسخهٔ ۱.۳.۰
- 🎼 **موزیک استودیویی رندرشده**: هر ۱۱ قطعه (۱۰ فصل + منو) با **سنتز فیزیکی مدل‌سازی‌شده** آفلاین رندر شده‌اند — سنتورِ چکشی با هارمونیک‌های ناهماهنگ و ضربهٔ مالِت، نیِ نفس‌دار با ویبراتوی تأخیری، کمانچهٔ آرشه‌ای با فرمنت‌های بدنه، تنبک/دف مدالی، پد گرم و ریورب کانولوشن واقعی + مسترینگ (نرم‌ساز، نرمالایز بلندی، لوپ بی‌درز). دیگر هیچ صدای تیز و مصنوعی وجود ندارد.
- 🖼️ **گرافیک در سطح موتورهای بازی**: هر ۱۱ پس‌زمینه از نو با عمق سینمایی، نور حجمی و ترکیب‌بندی لایه‌ای تولید شد + تبدیل به **WebP بهینه** (۳۰ تا ۵۰٪ سبک‌تر — رفع کامل لودِ کندِ فصل ۳).
- 🐦 **«سیمرغک» — شخصیت راهنما**: پرندهٔ افسانه‌ای شاهنامه با ۳ حالت (شناور/اشاره/جشن) که در منو خوش‌آمد می‌گوید، در آموزش قدم‌به‌قدم درس می‌دهد و پیروزی را جشن می‌گیرد.
- ✋ **آموزش کاملِ کشیدن حروف**: دستِ سفید کوکی‌بازی، **روی حروف واقعیِ اولین واژه** سفر می‌کند (نه یک مسیر فرضی) و سیمرغک هر قدم را توضیح می‌دهد.
- 🔘 **آیکون‌های گرافیکی واقعی**: کل آیکون‌های UI (راهنما، بُر، بازگردانی، سکه، ستاره، قفل، هدیه،…) به مجموعهٔ **توپُرِ دوتُنه** طلایی ارتقا یافت — همهٔ ایموجی‌ها حذف شدند.
- ⭕ **چرخ حروف بزرگ‌تر**: حروف ۶۲px (قبلاً ۵۶) با فاصلهٔ بیشتر و هدف لمسیِ بزرگ‌تر — دقیق و راحت.
- 🎛️ **دکمه‌های کمکی مرتب و زیبا**: سه دکمهٔ گرافیکی دایره‌ای **زیر چرخ** — دیگر هیچ تداخلی با جدول و واژه‌ها نیست.
- 📊 **نوار پیشرفت پله‌ای فصل‌ها**: ۱۰ پلهٔ طلایی با درخشش متحرک، جای نوار سادهٔ قبلی.
- 🟫 **زمینهٔ قهوه‌ای طرح‌دار**: الگوی گرهِ «ستاره‌وچلیپا» روی همهٔ پنل‌ها، منو و صفحه‌ها + پس‌زمینهٔ منو کاملاً ایرانی (میدان نقش‌جهان).
- ✨ **افکت‌های درخشان‌تر**: کانفتی روبانی، حلقهٔ ستارهٔ طلایی هنگام یافتن واژه، رندر افزایشی (additive) ذرات نورانی.
- 🎼 **موسیقی کاملاً از نو**: برای هر فصل یک ملودیِ دست‌نویس روی گام دستگاهی همان فصل — با فرم «سؤال و جواب»، سکوتِ میان جملات، نُت‌های کشدار و آرام، ضربِ ملایم دف/تنبک و اجرای انسانی‌شده. دیگر هیچ نُت تصادفی و عصب‌کننده‌ای وجود ندارد.

- 🗺️ **۱۰۰ مرحله در ۱۰ فصل** — باغ نخستین، بازار رنگ‌ها، کویر زرین، جنگل مه‌آلود، قلعه کوهستانی، شهر بادگیرها، ساحل مروارید، روستای پلکانی، شب ستاره‌ها و باغ واژه‌ها
- 🌱 **مکانیک «دنیای زنده»** — هر واژه‌ای که پیدا می‌کنید یک عنصر محیطی را در صحنه زنده می‌کند (پراپ‌های SVG اورجینال با انیمیشن ورود + ذرات نور)
- 🧩 **جدول کراس‌ورد راست‌به‌چپ** — مولد خودکار چیدمان با اعتبارسنجی کامل؛ واژه‌ها از **واژه‌نامهٔ ۸۲۹ واژه‌ای** واژه‌های واقعی فارسی انتخاب می‌شوند — **بدون حتی یک واژهٔ تکراری در کل بازی**
- 🎵 **موسیقی سنتی ایرانی رویه‌ای (Procedural)** — ملودی‌های **آهنگ‌سازی‌شدهٔ دستی** برای هر فصل (فرم سؤال و جواب با سکوتِ نفس‌گیر) روی گام‌های دستگاهی (شور، همایون، سه‌گاه، دشتی، ماهور، چهارگاه، نوا، راست، ابوعطا، افشاری) با کوک میکروتون، اجرای انسانی‌شده (ویبراتوی تأخیری، جرئت‌نوانی، تزئین)؛ سازهای **سنتور، نی و کمانچه** + ضرب **دف و تنبک** در ریتم‌های ۴/۴ و ۶/۸ + ریورب کانولوشن — **صد در صد اورجینال، بدون هیچ فایل صوتی**
- 🔊 **۱۲ افکت صوتی سینتزشده** — انتخاب حرف (بر اساس گامِ فصل!)، واژه درست/غلط، سکه، راهنما، تکمیل مرحله، انفجار آتش‌بازی، گشایش فصل و…
- 🎨 **تم قهوه‌ای/طلایی پریمیوم** — کاشی‌های کرم با **حروف قهوه‌ای**، چرخِ چوبی، قاب تزئینی گره‌چینی، پس‌زمینه‌های نقاشی‌شدهٔ اختصاصی هر فصل، پارالاکس، ذرات محیطی (گلبرگ، شن، برف، کرم شب‌تاب، ستاره…)
- 📖 **صفحهٔ «راهنما»ی کامل + آموزش تعاملی** — چطور بازی کنیم، امتیازها، نکته‌ها
- ⭐ **سیستم پیشرفت کامل** — ستاره (۳تایی برای هر مرحله)، سکه، واژه‌های پنهان (Bonus)، راهنما، بُر و بازگردانی، صندوقچه پایان فصل، هدیه روزانه، ذخیره‌سازی خودکار (localStorage — بدون بک‌اند)
- 📱 **آفلاین و سبک** — کل بازی سمت کلاینت اجرا می‌شود؛ نسخهٔ اندروید با Capacitor

## 🕹️ نحوه بازی

انگشت (یا موس) را روی حروف چرخ بکشید تا واژه بسازید. واژه‌های جدول را کامل کنید تا صحنه‌ی فصل جان بگیرد. واژه‌هایی که در جدول نیستند ولی از حروف چرخ ساخته می‌شوند **واژه پنهان** هستند و سکه می‌دهند (هر واژهٔ واقعی فارسیِ ساخته‌شده از حروف چرخ پذیرفته می‌شود). با سکه می‌توانید راهنما بخرید. جزئیات بیشتر در صفحهٔ «راهنما»ی خود بازی.

## 🛠️ تکنولوژی

| بخش | انتخاب | چرا |
| --- | --- | --- |
| موتور | **HTML5 + TypeScript خالص (موتور اختصاصی)** | اجرای روان روی موبایل، باندل سبک، آفلاین کامل، کنترل کامل RTL |
| پوسته | **Next.js 16 (App Router)** فقط به‌عنوان هاست استاتیک | پیش‌نمایش سریع، `CAP_STATIC=1` → خروجی استاتیک `out/` |
| بستهٔ اندروید | **Capacitor 6** | همان کد وب، APK امضاشده با GitHub Actions |
| گرافیک | CSS + SVG + Canvas 2D + تصاویر اختصاصی AI | کیفیت در هر رزولوشن، حجم کم |
| صدا | موزیک: فایل‌های OGG رندرشدهٔ آفلاین (سنتز فیزیکی Python) + افکت‌ها: Web Audio API | کیفیت استودیویی + اورجینال بودن تضمین‌شده |
| داده مراحل | ۱۰ فایل JSON جداگانه + واژه‌نامه | ویرایش آسان مراحل بدون دست‌زدن به کد |
| ذخیره‌سازی | localStorage (نسخه‌دار) | بدون بک‌اند خارجی |

> چرا Unity/Godot نه؟ برای یک بازی پازل واژه‌محور، وب روی موبایل سریع‌ترین مسیرِ «اجرا بدون نصب» را می‌دهد و موتور اختصاصی، کنترل کامل روی RTL فارسی و حجم بازی را کم نگه می‌دارد. ساختار ماژولار کد (`src/game/*`) مستقل از Next.js است و با Capacitor به APK بومی می‌رسد.

## 🚀 اجرای پروژه (Run)

## 📦 Build

```bash
npm run build          # خروجی استاندارد Next.js
npm run build:static   # خروجی استاتیک (پوشه out/) برای Capacitor
npm run apk            # ساخت APK امضاشده: build:static + cap sync + gradle assembleRelease
```

خروجی APK: `android/app/build/outputs/apk/release/app-release.apk`
(امضا با keystore استاندارد debug که در ریپو هست تا نسخه‌ها قابل ارتقا باشند — برای انتشار در استور، keystore شخصی خودتان را جایگزین کنید.)

## 🤖 ساخت خودکار APK با GitHub Actions

با push کردن یک تگ، اکشن `Build & Release APK` اجرا می‌شود:

```bash
git tag v1.1.0
git push origin v1.1.0
```

مراحل اکشن: نصب وابستگی‌ها → اعتبارسنجی ۱۰۰ مرحله → build استاتیک → `cap sync` → `gradle assembleRelease` → آپلود Artifact → ساخت GitHub Release با فایل APK. (به هیچ Secret ای نیاز ندارد.)

## 💰 اتصال پرداخت درون‌برنامه‌ای و تبلیغات (مایکت / کافه‌بازار / AdMob)

لایهٔ آماده در `src/game/core/monetization.ts` پیاده شده است؛ UI فروشگاه کامل به آن وصل است و بدون پلاگین هم (حالت شبیه‌سازی) قابل تست است. برای اتصال واقعی فقط یک پلاگین کوچک Capacitor لازم است:

1. **قرارداد پل (JSON) — پلاگین باید این چهار متد راExpose کند:**
   ```ts
   VzBilling.purchase(productId): Promise<{ ok: boolean; orderId?: string; error?: string }>
   VzBilling.owned():               Promise<{ ok: boolean; owned: string[] }>
   VzAds.showRewarded():            Promise<{ completed: boolean }>
   VzAds.showInterstitial():        Promise<{ ok: boolean }>
   ```
   پل باید روی `window.VzBilling` / `window.VzAds` (یا `Capacitor.Plugins.VzBilling/VzAds`) در دسترس باشد. تشخیص خودکار است: تا وقتی پل نباشد، همه‌چیز شبیه‌سازی می‌شود؛ به‌محض اضافه‌شدن پلاگین، خرید و تبلیغ واقعی می‌شوند — **بدون هیچ تغییری در کد UI**.

2. **SDKهای پشت پل:**
   - کافه‌بازار → [Poolakey](https://github.com/CafeBazaar/GameHub-Poolakey) (IAB بازار)
   - مایکت → Myket In-App Billing
   - تبلیغات → Google AdMob (Rewarded + Interstitial)

3. **شناسهٔ محصولات** (باید در کنسول هر دو استور دقیقاً با همین شناسه‌ها ساخته شوند):
   `coins_50` · `coins_250` · `coins_550` · `coins_1200` · `golden_bundle` · `remove_ads`
   (فهرست رسمی و قیمت‌ها: `SKUS` در `monetization.ts`)

4. **جایگاه‌های تبلیغاتی که از الان در بازی رزرو شده:**
   - ویدیوی جایزه‌دار «سکهٔ رایگان» در فروشگاه (فعال، با کول‌داون)
   - Interstitial بین فصل‌ها (تابع `showInterstitialAd` آماده است؛ پس از خرید «حذف تبلیغات» هر دو جایگاه غیرفعال می‌شوند — `Save.data.adsRemoved`)
