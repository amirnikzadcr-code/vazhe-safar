# واژه‌سفر — Safar-e Vazhe 🌙

**سفری واژه‌به‌واژه در سرزمینِ قصه‌ها**

یک بازی پازل کلمات موبایلی، **اورجینال** و ایرانی‌الهام: با پیدا کردن هر واژه، دنیای بازی جان می‌گیرد — درخت‌ها سبز می‌شوند، چراغ‌های بازار روشن می‌شوند، کاروان از کویر می‌گذرد و ستاره‌ها در آسمان ظاهر می‌شوند.

> an original, Iranian-inspired word-puzzle journey where every discovered word brings a living world to life.

---

## ✨ ویژگی‌ها (Features)

- 🗺️ **۱۰۰ مرحله در ۱۰ فصل** — باغ نخستین، بازار رنگ‌ها، کویر زرین، جنگل مه‌آلود، قلعه کوهستانی، شهر بادگیرها، ساحل مروارید، روستای پلکانی، شب ستاره‌ها و باغ واژه‌ها
- 🌱 **مکانیک «دنیای زنده»** — هر واژه‌ای که پیدا می‌کنید یک عنصر محیطی را در صحنه زنده می‌کند (پراپ‌های SVG اورجینال با انیمیشن ورود + ذرات نور)
- 🧩 **جدول کراس‌ورد راست‌به‌چپ** — مولد خودکار چیدمان با اعتبارسنجی کامل (هیچ واژه تقلبی روی صفحه ساخته نمی‌شود)
- 🎵 **موسیقی رویه‌ای (Procedural) مخصوص هر فصل** — ساخته‌شده با Web Audio از گام‌های الهام‌گرفته از دستگاه‌های موسیقی ایرانی (شور، همایون، سه‌گاه، دشتی و…) با کوک میکروتون؛ **صد در صد اورجینال، بدون هیچ فایل صوتی**
- 🔊 **۱۱ افکت صوتی سینتزشده** — انتخاب حرف، واژه درست/غلط، سکه، راهنما، تکمیل مرحله، گشایش فصل و…
- 💎 **UI پریمیوم موبایل** — RTL کامل، فونت Vazirmatn، انیمیشن‌های نرم، ذرات محیطی هر فصل (گلبرگ، شبنم، برف، کرم شب‌تاب، ستاره…)، پارالاکس، کرکره‌های شیشه‌ای (Glassmorphism)
- ⭐ **سیستم پیشرفت کامل** — ستاره (۳تایی برای هر مرحله)، سکه، واژه‌های پنهان (Bonus)، راهنما، بُر و بازگردانی، صندوقچه پایان فصل، هدیه روزانه، ذخیره‌سازی خودکار (localStorage — بدون بک‌اند)
- 📱 **آفلاین و سبک** — کل بازی سمت کلاینت اجرا می‌شود؛ بدون نیاز به سرور، بدون تبلیغ، بدون جمع‌آوری داده

## 🕹️ نحوه بازی

انگشت (یا موس) را روی حروف چرخ بکشید تا واژه بسازید. واژه‌های جدول را کامل کنید تا صحنه‌ی فصل جان بگیرد. واژه‌هایی که در جدول نیستند ولی از حروف چرخ ساخته می‌شوند **واژه پنهان** هستند و سکه می‌دهند. با سکه می‌توانید راهنما بخرید.

## 🛠️ تکنولوژی

| بخش | انتخاب | چرا |
| --- | --- | --- |
| موتور | **HTML5 + TypeScript خالص (موتور اختصاصی)** | اجرای روان روی موبایل، باندل سبک، آفلاین کامل، توسعه‌پذیری و قابلیت انتقال آسان به Capacitor/Unity در آینده |
| پوسته | **Next.js 16 (App Router)** فقط به‌عنوان هاست استاتیک | پیش‌نمایش سریع، استقرار ساده روی هر هاست استاتیک |
| گرافیک | CSS + SVG + Canvas 2D (ذرات) | کیفیت وکتور در هر رزولوشن، بدون حجم سنگین |
| صدا | Web Audio API (سینتز زنده) | اورجینال بودن تضمین‌شده + حجم صفر |
| داده مراحل | ۱۰ فایل JSON جداگانه | ویرایش آسان مراحل بدون دست‌زدن به کد |
| ذخیره‌سازی | localStorage (نسخه‌دار) | بدون بک‌اند خارجی |

> چرا Unity/Godot نه؟ برای یک بازی پازل واژه‌محور، وب روی موبایل سریع‌ترین مسیرِ «اجرا بدون نصب» را می‌دهد و موتور اختصاصی، کنترل کامل روی RTL فارسی و حجم بازی را زیر ۳ مگابایت نگه می‌دارد. ساختار ماژولار کد (`src/game/*`) مستقل از Next.js است و در صورت نیاز قابل انتقال به بومی (Capacitor) است.

## 🚀 اجرای پروژه (Run)

```bash
bun install        # یا npm install
bun run dev        # npm run dev  →  http://localhost:3000
```

## 📦 Build

```bash
bun run build      # خروجی استاندارد Next.js
bun run start      # اجرای نسخه production
```

برای خروجی موبایل بومی، پروژه با [Capacitor](https://capacitorjs.com/) سازگار است: `npx cap add android` پس از build استاتیک.

## 🧪 اعتبارسنجی مراحل

```bash
bun scripts/validate_words.ts
```

این اسکریپت برای هر ۱۰۰ مرحله بررسی می‌کند: واژه‌ها فقط از حروف چرخ ساخته‌شوند، واژه تکراری نباشد، و مولد کراس‌ورد بتواند چیدمان فشرده و معتبر بسازد.

```

│   │   ├── page.tsx            # مونتاژ موتور بازی

│       │   ├── engine.ts       # مدیریت صحنه‌ها و ناوبری
│       │   ├── audio.ts        # موسیقی رویه‌ای + افکت‌ها (Web Audio)
│       │   ├── save.ts         # ذخیره‌سازی نسخه‌دار localStorage
│       │   └── utils.ts        # ابزارها (DOM، RNG، ارقام فارسی…)
│       ├── data/
│       │   ├── chapters.ts     # هویت بصری/صوتی ۱۰ فصل
│       │   └── levels/         # ⬅️ ۱۰۰ مرحله در ۱۰ فایل JSON (قابل ویرایش)
│       ├── fx/
│       │   ├── particles.ts    # موتور ذرات (گلبرگ، برف، ستاره، آتش‌بازی…)
│       │   └── props.ts        # ۴۳ پراپ SVG صحنه
│       ├── ui/
│       │   ├── gameplay.ts     # صفحه گیم‌پلی (صحنه زنده + جدول + چرخ)
│       │   ├── screens.ts      # منو، فصل‌ها، مراحل، تنظیمات، پیشرفت، جوایز
│       │   ├── wheel.ts        # چرخ حروف با کشیدن انگشت
│       │   └── components.ts   # دکمه‌ها، مودال‌ها، توست‌ها
│       ├── crossword.ts        # مولد کراس‌ورد RTL با اعتبارسنجی

├── public/assets/
│   ├── bg/                     # ۱۱ پس‌زمینه تصویری فصل‌ها و منو (تولید هوش مصنوعی)
│   ├── fonts/                  # Vazirmatn (+ لایسنس OFL)
│   └── icons/                  # آیکون بازی
├── scripts/
│   ├── gen_assets.sh           # بازتولید پرامپت‌دار تصاویر
│   └── validate_words.ts       # اعتبارسنجی داده ۱۰۰ مرحله
```

## 🔐 امنیت

- هیچ توکن، کلید API، رمز یا Credential در این ریپو قرار ندارد.
